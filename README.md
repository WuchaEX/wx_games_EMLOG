# 🎮 棋牌大厅 (wx_games)

> 一款为 **Emlog CMS** 打造的 **棋牌游戏合集** 插件。一站集成多款 H5 棋牌游戏，当前包含 **H5斗地主**、**H5国标麻将** 和 **H5斗牛**，可随时扩展。
>
> 作者：**舞嗏** (WuchaEX) | 演示站：https://www.20090729.cn

## ✨ 大厅功能

- **游戏大厅**：选择想玩的游戏，登录后可保存战绩
- **独立开关**：后台可单独开启/关闭每个游戏，关闭后前台不显示入口
- **数据看板**：后台首页展示各游戏玩家数、对局数、最高分、活跃度等指标
- **导航入口**：前台自动添加「🎮 棋牌大厅」菜单链接
- **通用道具**：昵称变色/特效等道具可跨游戏使用，一次购买全游戏有效

## 🗄️ 数据库（7张表）

| 表 | 用途 | 说明 |
|----|------|------|
| `wx_games_scores` | 用户积分/战绩 | 统一存储，`game` 字段区分游戏（ddz/mj/niuniu） |
| `wx_games_logs` | 积分变动日志 | 全游戏共享流水表 |
| `wx_games_shop_items` | 商城商品 | `is_global` 标记通用道具（跨游戏可用） |
| `wx_ddz_games` | 斗地主游戏记录 | 防逃跑 + 历史对局 |
| `wx_niuniu_games` | 斗牛游戏记录 | 防逃跑 + 历史对局 |
| `wx_games_user_items` | 玩家背包 | 统一存储，`game` 字段区分归属游戏 |
| `wx_games_mall_logs` | 商城消费记录 | 全游戏统一消费流水 |

## 📥 安装

1. 将 `wx_games` 文件夹上传至 emlog 的 `content/plugins/` 目录
2. 进入 emlog 后台 → 插件管理 → 启用「棋牌大厅」
3. **停用旧插件**：确保 `wx_ddz`（H5斗地主）和 `wx_mojang`（H5麻将）已停用（函数名冲突）
4. 访问 `你的域名/?plugin=wx_games` 进入游戏大厅
5. 游戏数据（积分、商城、战绩）**自动继承**，无需迁移

> ⚠️ 旧插件的数据表（`wx_ddz_*` / `wx_mojang_*`）保留原名，启用 wx_games 后数据直接可用。
